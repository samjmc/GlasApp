VULNERABILITY CONFIRMED
================================================================================

Location: server/replitAuth.ts:182-196 (isAuthenticated middleware)

Before Fix:
  if (!isReplitEnvironment) {
    req.user = {sub: "dev-user-123"} // ANY unauthenticated user gets this
  }

Impact:
  - Every unauthenticated user can access private routes
  - Users can delete votes, save quizzes, trigger LLM jobs
  - No authentication required
  - Trust is completely broken

After Fix:
  - NODE_ENV=development: dev-user-123 allowed (local testing)
  - NODE_ENV=production: Bearer token required
  - Unauthenticated requests: 401 Unauthorized
