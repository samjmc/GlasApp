# Project Memory

Each project (or initiative) gets its own memory folder:

```
.claude/projects/
  my-project/
    memory/
      MEMORY.md          # index
      user_role.md       # who you are, context
      feedback_*.md      # how to work with you
      project_*.md       # what you're building, deadlines, goals
      reference_*.md     # where to look for info
```

Memory persists across sessions. Use it to capture:
- Non-obvious architecture decisions
- Past bugs and their fixes
- Preferences (code style, patterns you like/avoid)
- Project context (deadlines, stakeholders, constraints)
- Learnings worth keeping for similar work

See `~/.claude/projects/C--rwa-work-workspace/memory/MEMORY.md` for an example.
