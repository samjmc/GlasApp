# Rules

These are guardrails, not laws. They exist because they've prevented mistakes.

- **planning-discipline.md** — why you plan before coding
- **coding-discipline.md** — write minimal, correct code
- **git-discipline.md** — safe, clear git practice

Read them once. Reference them when starting work. If a rule feels wrong for your case, that's worth questioning — but usually it's there for a reason.
